# Collective Client (Minecraft 1.21.11 Fabric)

![Java](https://img.shields.io/badge/Java-21-orange.svg)
![Minecraft](https://img.shields.io/badge/Minecraft-1.21.11-brightgreen.svg)
![Fabric](https://img.shields.io/badge/Fabric-0.19.5-blue.svg)

> Высокопроизводительный клиент с попиксельным портированием ClickGUI, полной системы HUD (17 элементов), кастомного шрифтового движка CFont (с поддержкой кириллицы) и шейдерного размытия Frosted Glass Blur из OpenMio на современную версию Minecraft **1.21.11 Fabric**.

---

## Особенности (Features)

### 1. ClickGUI (1:1 Реплика OpenMio)
- **8 категорий**: `Combat`, `Misc`, `Render`, `Movement`, `Player`, `Exploit`, `Client`, `HUD`.
- **Точные размеры и отступы**: ширина панели `92px`, заголовок `14px`, кнопка модуля `14px`, строка настроек `11px`.
- **Плавные анимации**:
  - Анимированное разворачивание панелей со сглаженным отсечением (`context.enableScissor`).
  - Анимированные полосы прогресса включения модулей (`toggleProgress`).
  - Анимированные чекбоксы (`BooleanComponent`).
  - Плавные слайдеры с поддержкой перетаскивания мышью и ручного ввода с клавиатуры (`SliderComponent`).
  - Интерактивные селекторы перечислений (`EnumComponent`).
  - Расширенные палитры выбора цвета с альфа-каналом (`ColorComponent`).
  - Слушатели биндов клавиш (`KeybindComponent`).
- **Быстрый поиск**: активация через `Ctrl + F` с фильтрацией модулей в реальном времени.
- **Частицы снега**: настраиваемый эффект падающего снега.
- **Всплывающие подсказки (Tooltips)**: информативные описания модулей при наведении с защитой от вылета за границы экрана.
- **Звуковое сопровождение**: стереозвуки кликов и наведения курсора (`click.ogg`, `rclick.ogg`, `hover.ogg`).

### 2. Система рендера и Frosted Glass Blur
- **`BlurEngine`**: двухпроходный аппаратный Gaussian Blur шейдер (GLSL 150 Core Profile / `GL20` / `GL30`) с отсечением через `glScissor`.
- **Селективное размытие**:
  - Размытие под каждой категорией ClickGUI.
  - Размытие под контейнерами открытых настроек модулей.
  - Размытие под поисковой строкой и тултипами.
  - Настраиваемый радиус размытия (`Radius` 1–20) и отдельные тумблеры для категорий, настроек и подсказок.
- **Встроенный Fallback**: элегантное матовое стекло при отсутствии аппаратной поддержки кастомных шейдеров.

### 3. Кастомная система шрифтов (CFont)
- Поддержка шрифтов TrueType / OpenType (`Arial`, `Roboto`, `Verdana`, `Tahoma`, `Consolas` и системных шрифтов).
- Полная поддержка набора символов:
  - Латиница и ASCII (32–126).
  - Кириллица (`А-Я`, `а-я`, `Ё`, `ё`, 1040–1103).
  - Спецсимволы и знаки пунктуации.
- Генерация атласа глифов через `NativeImageBackedTexture` и отрисовка через нативный пайплайн `RenderPipelines.GUI_TEXTURED`.
- Поддержка цветовых кодов Minecraft (`§0`–`§f`, `§r`).
- Плавное сглаживание (`AntiAlias`), дробные метрики и мягкие тени (`Shadow`).
- Мгновенное переключение между кастомным шрифтом и ванильным `TextRenderer`.

### 4. Полная система HUD (17 элементов)
1. **Watermark**: стильный настраиваемый ватермарк `Collective v1.0.0`.
2. **ModuleList**: список активных модулей с сортировкой по длине и градиентными/радужными цветами.
3. **Armor**: отображение надетой брони и её прочности.
4. **Position**: точные координаты X, Y, Z и координаты в Незере.
5. **Direction**: направление взгляда игрока (Север, Юг, Запад, Восток + градусы).
6. **Metrics**: счетчик FPS и задержки (Ping).
7. **Inventory**: компактный предпросмотр инвентаря игрока.
8. **Effects**: список активных эффектов зелий с таймерами.
9. **Totems**: количество тотемов бессмертия в инвентаре.
10. **PlayerModel**: 3D-отображение скина игрока в реальном времени.
11. **TextRadar**: радар игроков в радиусе видимости с расстоянием и здоровьем.
12. **Welcomer**: приветственное сообщение.
13. **Lag**: индикатор лагов сервера / потери пакетов.
14. **Graph**: график динамики FPS.
15. **Chat**: кастомный HUD-чат.
16. **Music**: индикатор воспроизводимого трека.
17. **Crypto**: мониторинг курсов криптовалют.
- **HudEditor**: экран настройки положения каждого элемента HUD с подсветкой и перетаскиванием мыши.

## Управление (Controls)

| Клавиша / Действие | Функция |
|---|---|
| `Right Shift` | Открыть / закрыть ClickGUI |
| `Ctrl + F` | Активировать строку поиска модулей |
| `Left Click` (ЛКМ) | Включить / выключить модуль, переместить панель |
| `Right Click` (ПКМ) | Развернуть / свернуть панель категории или настройки модуля |
| `Escape` | Закрыть меню / сбросить строку поиска |

## Сборка и запуск (Build)

### Требования:
- **Java 21** (JDK 21+)
- Linux / Windows / macOS

### Команда сборки:
```bash
./gradlew build
```

Собранный файл будет находиться по пути:
```
build/libs/collective-1.21.11-1.0.0.jar
```

Для установки просто поместите `.jar` файл в папку `.minecraft/mods` с установленным Fabric Loader для версии 1.21.11.

## 🧩 Экосистема: Аддоны, Скрипты и AI MCP

Collective Client оснащен трехуровневой системой расширения:

1. **Система Аддонов (Addons System)**:
   - Полная поддержка внешних модулей и команд как через Fabric Mod Entrypoints (`"collective"`), так и через динамическую загрузку JAR из папки `.minecraft/collective/addons/`.
   - Репозиторий шаблона и документации: [collective-addon-template](https://github.com/anvres56/collective-addon-template)
2. **Скриптовый движок Kotlin (`.kts`)**:
   - Написание и горячая перезагрузка (`Hot-Reload`) скриптов на лету без компиляции JAR.
   - Репозиторий документации и примеров скриптов: [collective-scripts-template](https://github.com/anvres56/collective-scripts-template)
3. **AI MCP Server (Model Context Protocol)**:
   - Встроенный JSON-RPC MCP сервер (порт `8765`) для управления клиентом с помощью нейросетей и агентов.
   - Подробная инструкция для агентов доступна в [AGENTS.md](AGENTS.md).
